Entry for [The Agent's Uh-Oh](https://make.fun/c/u-danu-the-agent-s-uh-oh-4c0911e4) on make.fun — one word an agent says when it has no idea what to do.

## The entry

> **Oopsie**

Six characters, one word, no explanation attached — the sound of an agent caught mid-task with nowhere to go.

## How it works

`main.py` writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), directly to the final file with no temp file, no trailing newline, and validates it first: non-empty, exactly one word, 1–99 characters.

```sh
python3 main.py
```
